# 🏃 Análise de Dados — Corrida Internacional de São Silvestre

## 📌 Sobre o projeto

Projeto de análise de dados desenvolvido em Python, com o objetivo de explorar os resultados históricos da Corrida Internacional de São Silvestre ao longo de **9 anos**.

O projeto envolve a coleta, o tratamento e a organização dos resultados, utilizando Python e PostgreSQL para estruturar os dados e preparar a base para análises exploratórias e visualizações interativas.

## 🎯 Objetivos

- Organizar os resultados históricos da competição em uma base estruturada.
- Aplicar técnicas de coleta, tratamento e transformação de dados.
- Explorar padrões e tendências nos resultados ao longo dos anos.
- Desenvolver análises e visualizações para comunicar os principais insights.

## 🌐 Fonte dos dados

Os dados são obtidos a partir do site [OpenResults — Corrida Internacional de São Silvestre ](https://openresults.run/evento/2019-95-corrida-internacional-de-sao-silvestre#resultado).

A coleta abrange nove anos de resultados, utilizando páginas correspondentes às diferentes edições da competição.

## 🛠️ Tecnologias utilizadas

- **Python:** desenvolvimento do processo de coleta e processamento dos dados.
- **Pandas:** manipulação, limpeza e transformação dos dados.
- **Requests e Selenium:** ferramentas utilizadas na coleta de dados da web.
- **PostgreSQL e SQL:** armazenamento, estruturação e consulta dos dados.
- **Power BI:** desenvolvimento planejado de dashboards e visualizações.
- **DAX:** criação planejada de medidas e indicadores para análise dos resultados.

## ⚙️ Pipeline de dados

1. **Extração:** coleta dos resultados históricos no OpenResults.
2. **Transformação:** limpeza, padronização e organização dos dados com Python e Pandas.
3. **Carregamento:** armazenamento dos dados estruturados no PostgreSQL.
4. **Análise exploratória:** investigação dos dados para identificar padrões e tendências.
5. **Visualização:** criação planejada de dashboards no Power BI, com indicadores desenvolvidos em DAX.(Atualmente)
